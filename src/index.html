Синхронизация

Не подключено — данные только на этом устройстве
Как настроить — 5 минут, бесплатно
  1. На github.com: «+» → New repository. Имя — например, travel-map-data. Обязательно выберите Private. Создайте.
  2. Аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Название — любое, срок (Expiration) — например, год. Repository access: Only select repositories → только репозиторий с данными.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  5. Generate token и сразу скопируйте его — GitHub покажет токен один раз.
  6. Вставьте сюда репозиторий и токен, нажмите «Подключить». На каждом устройстве — то же самое.
Токен хранится только в этом браузере и отправляется только на api.github.com; в файл приложения и версию для друзей он не попадает. Данные лежат в файле travel-data.json, каждая синхронизация — сохранённая версия в истории репозитория.

Резервная копия

GPX — для навигаторов и часов (Garmin, OsmAnd, Coros): маршруты треками, города точками. KML — для Google My Maps, Google Earth и Organic Maps: ещё и страны контурами, планы отдельным слоем.
Отметки хранятся только в этом браузере на этом устройстве. Файл — подстраховка на случай очистки данных или смены телефона: храните его у себя.

Файл читается прямо в браузере и никуда не отправляется. Домашний регион (40 км от дома) пропускается.
Как выгрузить историю из Google Maps
  1. Android: Настройки телефона → Местоположение → Сервисы геолокации → Хронология → «Экспортировать данные хронологии». Получится файл Timeline.json.
  2. iPhone: Google Карты → ваш профиль → Хронология → «⋯» → Настройки местоположения и конфиденциальности → «Экспортировать данные хронологии». Получится location-history.json.
  3. Старый архив Google Takeout (до 2024 года): файлы из папки Semantic Location History (можно выбрать сразу несколько) или Records.json.
Названия пунктов меню у Google иногда меняются; ищите «Хронология» и «Экспорт».
