Нажмите, чтобы выбрать один или несколько .gpx файлов
Название необязательно — если поездок несколько, каждый трек получит имя из файла (или "Название — имя файла", если поле заполнено). Год, цель, компания, сезон, поездка и цвет будут общими для всех.
При сохранении маршрут попробует построить путь по реальным дорогам между городами. Если сервис маршрутизации недоступен — точки соединятся прямой линией, об этом сообщит подсказка. Название необязательно — по умолчанию возьмётся «Первый город — Последний город».
Если также указать хотя бы одно фото выше — первое станет обложкой мини-карточки со ссылкой на пост.
