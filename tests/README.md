# Автотесты

Тесты открывают `index.html` и `friends/index.html` из этого репозитория в настоящем
Chromium — в раскладке телефона и ПК — и проверяют основные сценарии: загрузку
без ошибок, правку записей, GPX, безопасность импорта, тёмную тему, мобильные
вкладки, регионы России, тепловую карту и приватность версии для друзей.
Сеть не нужна: запросы к картам и геокодеру подменяются или блокируются.
Данные в тестах синтетические — настоящие записи не используются.

На GitHub тесты запускаются сами при каждой загрузке файлов (вкладка **Actions**).
Зелёная галочка у коммита — всё в порядке, красный крестик — что-то сломалось;
отчёт со снимками экрана — в запуске, раздел *Artifacts → playwright-report*.

Запуск на своём компьютере (нужен Node.js 20+):

```
npm ci
npx playwright install chromium
npx playwright test
```

## Регрессионные наборы

Раньше эти проверки делались вручную скриптами на настоящих данных; теперь они
идут в общем прогоне на синтетических наборах того же объёма:

| Файл | Что проверяет |
|---|---|
| `regress-scale.spec.js` | большой архив (`fixtures/large-data.js`: ~340 записей, 32 трека по 1,5–6 тыс. точек, 40 поездок) при замедлении процессора ×4: время запуска и отклика фильтров, списка, «Проверки данных», коллекций, тепловой карты, подписей, кадра глобуса — в пределах бюджета; все окна, карточки, страницы поездок и облёты без ошибок. Замеры видны в отчёте как пометки «замер» |
| `regress-robust.spec.js` | испорченные и вредоносные данные (`fixtures/broken-data.js`): все экраны работают, внедрённый код не выполняется, разметка из данных не попадает в страницу, битые записи откладываются |
| `regress-layout.spec.js` | на телефоне ничего не шире экрана (карта, вкладки, окна, страница поездки); кнопки и плашки карты не перекрываются; контраст подписей в светлой и тёмной темах не ниже 3:1 |
| `a11y.spec.js` | доступность (axe-core, WCAG 2 A/AA): главный экран и все окна меню в обеих темах — подписи полей, названия кнопок и окон, роли, контраст текста; нарушения уровней critical и serious роняют тест |
| `offline-sw.spec.js` | настоящий сервис-воркер на локальном сервере: после одного открытия приложение и загруженные подробные границы работают без сети |

Любое нарушение политики безопасности (CSP) в любом тесте считается ошибкой.
