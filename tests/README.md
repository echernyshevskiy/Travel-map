# Автотесты

Тесты открывают `index.html` и `friends/index.html` из этого репозитория в настоящем
Chromium — в раскладке телефона и ПК — и проверяют основные сценарии: загрузку
без ошибок, правку записей, GPX, безопасность импорта, тёмную тему, мобильные
вкладки, регионы России, тепловую карту и приватность версии для друзей.
Сеть не нужна: запросы к картам и геокодеру подменяются или блокируются.
Данные в тестах синтетические — настоящие записи не используются.

На GitHub тесты запускаются сами при каждой загрузке файлов (вкладка **Actions**).
Зелёная галочка у коммита — всё в порядке, красный крестик — что-то сломалось;
отчёт со снимками экрана — в запуске, раздел *Artifacts → playwright-report*.

Запуск на своём компьютере (нужен Node.js 20+):

```
npm ci
npx playwright install chromium
npx playwright test
```
